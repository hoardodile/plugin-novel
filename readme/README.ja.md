# 小説

hoardodile のコンテンツプラグインです。段組ページの小説リーダーで、章のナビゲーション、段落ごとのメッセージ、タイポグラフィ設定をホストアプリのビューアで提供します。

## 機能

- **txt**（UTF-8 / GB18030 / UTF-16 の自動検出、Shift_JIS / Big5 の明示指定も可）、**markdown**、**html/xhtml**、**epub**、**docx**、**fb2** に対応。章フォルダー（各ファイルが 1 章）や `.fb2.zip` コンテナも読めます。
- 段組ページの読書表示。フォントサイズ、行間、字間、背景、文字コードの設定が可能。章はカスタマイズ可能な正規表現で自動検出されます。
- 段落ごとのメッセージ、読書位置の保存、目次サイドシートからのジャンプ。
- ライブラリの検索フィルターで形式（EPUB / FB2 / DOCX / プレーンテキスト）ごとに絞り込めます。

## 要件

- hoardodile ≥ 0.1.8（詳しくはリポジトリの README を参照）。
- インストール前にリポジトリを信頼してください。プラグインコードは制限付きサンドボックス内でサーバー側として実行されます。
