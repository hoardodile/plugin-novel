# 小说

hoardodile 内容插件：双栏分页的小说阅读器，支持章节导航、段落留言与排版设置，界面与主应用保持一致。

## 功能

- 支持 **txt**（自动识别 UTF-8 / GB18030 / UTF-16，也可手动指定 Shift_JIS / Big5）、**markdown**、**html/xhtml**、**epub**、**docx** 与 **fb2** —— 包括章节文件夹（每个文件即一章）与 `.fb2.zip` 压缩容器。
- 双栏分页阅读，可调字号、行高、字间距、背景与文本编码；章节自动识别，支持自定义正则。
- 段落留言与阅读进度保存；目录侧栏一键跳转。
- 可在内容库搜索过滤器中按格式（EPUB / FB2 / DOCX / 纯文本）筛选资源。

## 要求

- hoardodile ≥ 0.1.8（详见仓库 README）。
- 安装前请确认信任该仓库——插件代码在受限沙箱中作为服务端代码运行。
